# JavaScript Higher-Order Functions (HOF)

**Higher-Order Function (HOF)** হলো এমন একটি ফাংশন যা অন্য একটি ফাংশনকে **আর্গুমেন্ট (Argument)** হিসেবে গ্রহণ করে অথবা অন্য একটি ফাংশনকে **রিটার্ন (Return)** করে।

JavaScript-এ ফাংশনগুলোকে **"First-class citizens"** বলা হয়, কারণ এগুলোকে ভেরিয়েবলে রাখা যায়, অন্য ফাংশনে পাঠানো যায় এবং রিটার্নও করা যায়।

## ১. HOF-এর মূল বৈশিষ্ট্য

একটি ফাংশন HOF হওয়ার জন্য নিচের **যেকোনো একটি** শর্ত পূরণ করতে হয়:

| শর্ত | বর্ণনা |
|------|--------|
| **Function as Input** | অন্য একটি ফাংশনকে ইনপুট হিসেবে নেয় |
| **Function as Output** | আউটপুট হিসেবে একটি নতুন ফাংশন দেয় |

## ২. প্র্যাকটিক্যাল উদাহরণ

### ক. ফাংশনকে আর্গুমেন্ট হিসেবে নেওয়া (Callback)

আমরা যখন `map`, `filter`, বা `reduce` ব্যবহার করি, তখন আমরা আসলে একটি ফাংশনকে অন্য ফাংশনের ভেতরে পাঠাই।

```javascript
const numbers =;[1][2][3][4][5]

// 'map' হলো HOF, '(n) => n * 2' হলো Callback
const doubled = numbers.map((n) => n * 2);

console.log(doubled); //[2][4][6][8][10]
