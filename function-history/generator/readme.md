### JS Generator function 

``
- সহজ ভাষায় বলতে গেলে, JavaScript Generator Function হলো এমন এক বিশেষ ধরনের ফাংশন যা মাঝপথে থেমে যেতে পারে এবং পরে আবার সেখান থেকেই শুরু হতে পারে।

- সাধারণ ফাংশন (Regular Function) একবার শুরু হলে শেষ না হওয়া পর্যন্ত থামে না এবং একটিমাত্র ভ্যালু return করে। কিন্তু জেনারেটর ফাংশন প্রয়োজন অনুযায়ী একাধিকবার ভ্যালু দিতে পারে।
``
---
``
১. জেনারেটর ফাংশন কী? (What is it?)
এটি একটি বিশেষ ফাংশন যা একটি Iterator Object রিটার্ন করে। এটি তৈরি করতে function কিওয়ার্ডের পাশে একটি স্টার * চিহ্ন দিতে হয় এবং ভ্যালু থামানোর জন্য yield কিওয়ার্ড ব্যবহার করা হয়।

২. কেন এটি প্রয়োজন? (Why do we need it?)
Memory Efficiency: এটি একসাথে সব ডেটা মেমোরিতে লোড করে না। যখন প্রয়োজন (on-demand), তখন ডেটা তৈরি করে।

- Infinite Sequences: আপনি এমন লুপ চালাতে পারেন যা তাত্ত্বিকভাবে অসীম, কিন্তু মেমোরি ক্র্যাশ করবে না।
- Custom Iterables: সহজে কাস্টম ইটারেটর তৈরি করা যায়।
- Pausing Execution: ফাংশনের স্টেট বজায় রেখে মাঝপথে কাজ থামিয়ে রাখা যায়।
``
---
৩. কীভাবে ব্যবহার করবেন? (How to use?)
- জেনারেটর ফাংশন ব্যবহার করতে হলে আমাদের next() মেথড কল করতে হয়। প্রতিবার next() কল করলে ফাংশনটি পরবর্তী yield পর্যন্ত চলে এবং থেমে যায়।
``

### What is iterator?
- সহজ ভাষায় বলতে গেলে, Iterator হলো জাভাস্ক্রিপ্টের এমন একটি স্ট্যান্ডার্ড বা নিয়ম (Protocol), যা ব্যবহার করে কোনো কালেকশন (যেমন: Array বা String) থেকে একে একে ডেটা বের করে আনা যায়।

- একটি বস্তু বা Object-কে তখনই Iterator বলা হয়, যখন তার মধ্যে একটি নির্দিষ্ট মেথড থাকে, যার নাম next()
